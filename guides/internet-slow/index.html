Mobile data is slow or not working

The internet works but is snail-slow, or doesn't work at all — try these steps in order.

Why mobile data becomes slow

Speed drops for a handful of reasons: weak signal where you are standing, too many people using the same tower (common in the evening and at crowded events), a data package that has run out or been slowed after its fair-use limit, wrong network settings on the phone, or other apps quietly using the connection in the background. Sometimes the problem is not speed at all — a wrong APN or a data limit set on the phone can make the internet feel broken even with full signal bars. The steps below separate phone problems from network problems, so you fix the right thing instead of changing settings at random.

Steps

  1. Toggle airplane mode
    Turn Airplane mode ON for 2 seconds, then OFF. It reconnects the network — the quickest fix.
  2. Check the network mode
    Keep Settings > SIM > Preferred Network Type on 4G/5G LTE. If '3G only' gets selected, the speed drops.
  3. Check the data limit/warning
    Settings > Network > Data Usage — if a 'Data limit' is set, the internet stops after it. Also check your package's remaining MBs.
  4. Reset APN settings
    Settings > SIM > Access Point Names > menu (3 dots) > Reset to default. A wrong APN can stop the internet from working entirely.
  5. SIM slot / carrier settings
    On dual SIM, check that the data SIM is selected for 'Mobile data' on the right slot. If needed, remove the SIM, clean it, and reinsert it.
  6. Check area coverage
    Is it slow for everyone or just you? Check with another phone — it could be a network tower issue in the area, which only the helpline can fix.
  7. Restart the phone
    A full restart refreshes the network registration and clears stuck data sessions. Try it if the airplane-mode toggle did not help.
  8. Test at a different place and time
    Run a speed test near a window or outside, then again at a different time of day. If the speed is fine elsewhere, the issue is coverage at that spot, not your phone.
  9. Turn off data saver restrictions
    Settings > Network > Data Saver — a strict data saver can slow apps down or block them. Also check that the app you are using is allowed to use background data.
  10. Reset network settings
    Settings > System > Reset > Reset Network Settings. This clears saved Wi-Fi networks and Bluetooth pairings along with the mobile settings, so you will need to reconnect to Wi-Fi afterwards — but it fixes stubborn data problems that nothing else touches.

Slow on Wi-Fi too?

If the internet is slow on both mobile data and Wi-Fi, the problem is more likely your phone or the app than the network. Restart the phone, update the browser or app you are using, and clear its cache. If only one website or app is slow while everything else loads quickly, that service itself is having trouble — there is nothing to fix on your side, and simply checking again after some time is the practical answer.

If data does not work at all

No internet at all, even with signal bars showing? First confirm your package is active and still has balance or data left — an expired package is the most common cause of a sudden total stop. Then check that Mobile Data is actually switched on for the right SIM, turn data roaming on if you are travelling outside your home network's area, and reset the APN to default as described above. If a brand-new SIM never gets data at all, the carrier may need to activate data on the number — one call to the helpline usually sorts it out.

When it is the carrier's problem

If other phones on the same network are also slow in your area, or your phone gets poor speed in places where it used to be fast, report it to your carrier's helpline and note the location and the times it happens. Tower faults and congestion are fixed by the carrier, not by changing phone settings. But if your phone is slow everywhere while a friend's phone on the same network is fast at the very same spot, get your phone checked — an antenna damaged by a drop can quietly ruin data speeds.

Keep your data fast

  • Renew your package before it expires — an inactive package looks exactly like a phone fault.
  • Install carrier and system updates when offered; they often contain modem and network fixes.
  • Download large files and app updates on Wi-Fi, and save your mobile data for daily use.
  • Note the time and place when you complain to the helpline — a pattern helps them find the fault.

Tips

  • Keeping a VPN on can halve your speed — turn the VPN off during the test.
  • Note the before-and-after difference on a speed test (speedtest.net).

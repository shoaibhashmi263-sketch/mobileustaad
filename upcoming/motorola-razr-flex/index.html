What we know so far

The Motorola Razr Flex is not officially announced yet; current information comes from reputable leaks and certifications. Its expected launch window is Dec 2026.

Based on the reports so far, the Razr Flex is expected to feature a 6.92-inch foldable OLED inner (2364 x 1728, 165Hz, HDR10+/Dolby Vision) + 4.97-inch OLED cover (1736 x 1140) display, the Snapdragon 8 Gen 5 (QTI SM8845, Geekbench listing) chipset, a 50 rear camera setup and a 5,000mAh battery. Like all pre-launch information, these details can change before the official unveiling.
